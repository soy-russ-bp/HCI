# Usability vs UX

First, we need to define each concept. HCI is the fundamental discipline that studies how humans interact with technology; usability focuses on measuring the effectiveness, efficiency, and satisfaction of users with a given system; UX focuses on the entire user interaction with the product, including emotional and psychological aspects. That said, <mark>usability and UX are sub-branches of HCI, and while usability measures a product's functionality, UX addresses how the user feels when using it.</mark>

One UX feature we can add to our project is gamification. <mark>We can make the user "feel" their progress in real time,</mark> showing them how they level up and setting daily goals to achieve to keep them on the app longer. We can verify this by <mark>measuring the user's usage time with the product, the number of consecutive days they're logged in, and the speed at which they level up.</mark>
