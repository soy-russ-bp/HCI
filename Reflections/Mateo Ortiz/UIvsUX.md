# UI vs UX
In order to differentiate UI from UX, we first have to define them. UX (User Experience) can be defined as <mark>"The cultivation of customer satisfaction and loyalty by optimally developing the usability and positive emotional response to visitor experiences with your site."</mark> That is, it focuses on the user's complete journey and how they feel when interacting with the product as a whole. On the other hand, UI (User Interface) encompasses <mark>"the physical and technical elements that enable the user to interact with the technology or product, i.e. the controls, buttons, etc.,"</mark> in other words, it is the visual representation (fonts, icons, component layout) that materializes what is defined by UX.

In this way, <mark>while the UX addresses the overall user journey and satisfaction (research, testing, emotional flows), the UI implements all the visual and interactive components in a clean and attractive way.</mark>

As a first example based on our project, <mark>I think of the design of our overall project flow. This involves UX work, since we must make the user feel comfortable navigating our app.</mark> Now, as a <mark>second example is giving a branding to our app, this involves choosing the colors, fonts and size of our visual elements, already previously defined in the UX work.</mark>
