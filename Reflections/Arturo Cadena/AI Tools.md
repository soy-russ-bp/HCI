# AI Tools
Using AI to produce UI has been something new to me. I used ChatGPT as my AI tool. First, I had to think about the prompts for a learning app (something similar to my project). At first glance, the result looked good and, in my opinion, ChatGPT did a better job than I could have done, but after analyzing probably the AI job wasn’t perfect.

The interfaces were responsive, attractive, the elements were clear, the structure was good and the generated code followed good practices such as semantic tags. But it was hard to use some parts of the interfaces, for example, there were no filters or categories for the activities, thing that surprised me because I specified this part in the prompts. The quality of the UI was regular, being the visual part the best one and the interaction the worst one, **`making me realize that we must prioritize and check twice how easy it is to use the UI if it was created by ChatGPT or any other AI`**. 

ChatGPT is probably one of the easiest tools to use and it took me less than 15 minutes and gave me everything to produce an UI. Now, if we want to add some usability attributes or build something good according to the “UI principles” the experience might change a little bit and not be so simple, but it’s still better than without AI. **`So, in few words, the experience is great and helpful even though sometimes can be challenging to produce a product with quality `**.

Probably, the UI didn’t fulfill all the usability attributes, and some things should change to do so, and that can take us to the next question: how to extend it include so the UI can include the usability attributes? **`To answer this, I’d say that I should consider and specify more to the tool that the UI must include them, even though I wrote them in the prompt, the instructions were so simple in this part because I thought that ChatGPT was going to get it and do it perfectly just for being “too smart”. Also more writing more prompts could have been better, because I just analyzed and use the first results `**.

After doing this, it is interesting to think what will happen to the UX in a world where the people try to use the AI everywhere. **`AI accelerates the process, but in my opinion this role must continue because there should be someone to know whether the attributes are there or not and studying this part is not technical at all. These tools might give you good feedback and specially in creating things, even though the analysis of the AI can be confusing and difficult to determine if they are great when you don’t have experience or knowledge `**.
