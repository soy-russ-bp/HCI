# UIvsUX
<mark>One difference between the two is what each one focuses on. UI centers on the physical, technical elements and look of the system, and UX in the whole experience of the user or how it feels with the product.</mark> Considering that, both of them are key to create a good product because we can have, for example a very attractive and intuitive app but at the same time something that force you to click through numerous screens (making this a terrible experience).

<mark>An example of UI in our project is when we are making the interfaces for the user to continue a course. To make this we have to consider: the icons of the courses, if they are gonna have a different color whether the course is started or not, the size of the text and progress bars, swipe button, the look of the path and so on.</mark> In this case we'd be considering just UI elements and not thinking about user experience. The most important thing here is how good the interfaces look.

<mark>An example of UX in our project is used in the same task, but instead of focusing just on the design or the look, we consider if the user finds it easily and feels good while doing the task. To be more specific, here the number of clicks can be used, because when the user must click too many times just for continuing the course, the experience of using the app can be tiring and frustrating.</mark> So, it is important to determine the necessary steps or clicks to give proper experience.
