# Usability vs UX
HCI, Usability and UX are concepts or fields that are somehow different and similar at the same time. HCI is a multidisciplinary field focused on the design and the interaction between users and computers. In the Usability definition it is also detected the term interaction, because how are we going to know how well a user in a specific context can use a product to achieve a defined goal effectively? There must be humans using products. And to provide meaningful and relevant experiences to users (which is UX), people using systems is the first step to do that. **`So, in a nutshell their relation is that the three of them study and focus on humans using systems and try to improve this interaction to achieve their goals `**.

One specific difference between UX and Usability is the range of factors that each one includes. While usability centers on ease of use and effectiveness, UX includes concepts such as emotions, perceptions, preferences and responses of users interacting with a system. An example of this difference in our project can be in a button to end an activity. **`If the button is a good size and it is easy to recognize among the others, it means there is usability but not necessarily UX. To include UX in this part a positive message can be added after clicking the button, giving the user a positive stimulation`**. 

**`A basic UX feature for our project could be giving the users a badge when they finish a course so they can share in their social media and especially LinkedIn. To map this attribute, we can use behavioral influence because this feature encourages consistent engagement through rewarding. There are ways to verify and measure this feature, for example, comparing the average time the person uses the app before and after implementing the badges and also by surveys asking if the badges make learning more engaging`**.
