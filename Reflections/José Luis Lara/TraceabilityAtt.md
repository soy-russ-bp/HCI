# Traceability Att
*José Luis Lara Rubio*

For our project, we focused on error prevention as a key usability attribute. We tried to achieve it by using standard icons, limiting the numbers of buttons on each screen and using a design system for a consistent interface.

We focused on error prevention because we thought <mark>the frustration of mistakes and confusing navigation could negatively impact the learning experience</mark> of our users. <mark>We did not want our users focusing on learning how to use our app instead of learning how to improve their softskills</mark>.

To measure error prevention, we initially used task completion as the key metric to reflect it (using a maze project). However the results were very poor, but we didn't really know why, so we decided to conduct think aloud testing to understand why users were making so many mistakes.

We could have alternatively recorded very similar information using screen recordings of users engaging with our app and analyzing the places where they made mistakes, but by using a Maze project the process was very efficient and more easily replicated.
